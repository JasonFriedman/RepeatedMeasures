Repeated Measures

MATLAB software for running psychophysics and motor control experiments, built on top of the Psychtoolbox.

View on GitHub Download .zip Protocol reference

How it works

An experiment is described in a protocol file (XML): the recording devices to use, and a list of trials. Each trial says what is shown (the stimulus), how the trial starts, and what counts as a response.

Repeated Measures runs the trials, records from all the devices at the same time, marks events (stimulus onset, beeps, triggers) in the data, gives feedback, and saves one data file per trial. Each device runs in its own server, so recording continues at the device's own rate while the screen is updated.

It has been tested on macOS and Windows, although many of the devices only work with Windows.

Writing protocols

Protocol files are usually generated by a short MATLAB script. The protocol builder takes care of devices, instructions, repetitions, randomization, breaks and file names, and checks every option as it is set:

p = protocolNew;
p = protocolDevice(p,'tablet','maxx',48767,'maxy',30479);
p = protocolInstruction(p,'Press space to start');
conditions = protocolDesign('side',{'left','right'},'soa',[0 50 150]);
p = protocolBlock(p,conditions,@myTrial,'repetitions',12);
protocolSave(p,'protocols/subject1.xml');

What it supports

Recording devices

  • Keyboard
  • Mouse
  • Wacom tablets
  • Polhemus Liberty, Fastrak, G4
  • trakStar
  • Optotrak
  • CyberGlove
  • Force sensors (DAQ, ATI)
  • NI-DAQ, Measurement Computing DAQ
  • Arduino
  • Serial port
  • Gazepoint eye tracker
  • Bluetera, Red Amber IMUs
  • GoPro and video

Stimuli

  • Text
  • Images and image sequences
  • Video
  • Shapes and fixation
  • Random dot kinematograms
  • Symbols and text arrays
  • Finger opposition sequences
  • Virtual reality

Responses and trial starts

  • Key presses and sequences
  • Buttons and pedals
  • Mouse targets
  • Reaching to targets in space
  • Point-to-point movements
  • Movement thresholds
  • Colors in an image
  • External triggers

Also: beeps and sounds, serial, parallel, DAQ and Arduino triggers, a detection response task (DRT), QUEST staircases and on-screen feedback.

Testing

A test suite runs whole experiments with simulated devices, so it works with or without devices plugged in, in MATLAB or GNU Octave:

cd tests
results = runAllTests;
