dimensionsToUsematrixNaNDimensions to use to compare the target position , e.g. to just use x and y and not z, set to [1 2]. Default (NaN) is to use all dimensions. The number of dimensions should match the number of dimensions of the targets as defined in targetPosition. Alternatively, it can be set to how much to multiply the values with each row referring to one output dimension, e.g. if there are two xyz sensors, then [0.5 0 0 0.5 0 0;0 0.5 0 0 0.5 0]would generate an average of sensor 1 and 2. In this case, the number of rows should match the dimensions of the targets.
