Response

pointToPoint

Used in trial{n}.targetType

This response is for (possibly repeated) point to point measurements.

NameTypeDefaultDescription
startrequirednumber1The start point for the centre out movement (the number of a target from those defined in setup.targetPosition)
endrequirednumber2The end point for the centre out movement (the number of a target from those defined in setup.targetPosition)
startDistancenumber0.02How close to the start point you need to be to start a trial (inf for any distance), relative to screen width (1 = screen width)
endDistancenumber0.02How close to the end point you need to be to end a trial (inf for any distance), in pixels
repetitionsrequirednumber10Number of repetitions to perform. The trial will end when this number of repetitions has been reached (or the recordingTime has been reached)
beepbooleanfalseWhether to beep after each successful movement
endtimenumber0The amount of time (in seconds) that you need to be at the target for
