Recording device

NIDAQ

Used in setup.NIDAQ

This client connects to a NIDAQ server to sample one or more channels (e.g. for a button box or force sensors).

showPositionTypestring'dot'If showing position, how to show the current position (either 'dot','line','ellipse', 'rectangle' or 'image' or the name of a function with an @ before it). Line means a line from the last point to the current point. Note that if showPosition=1, it will always be shown. If showPosition=2 and imagestimulus is used,it will only be shown when in state 1. If showPosition=3, then the fields below will be used to determine the position. If showPosition=4, it is the same as 3, but the position is only shown until the trial starts. If showPosition=5, it is the same as 3, but if using image stimuli, only show position if it is in state 1.If using a function, the function will get called every frame (data can be stored between calls in the thistrial struct): thistrial = yourFunctionName(experimentdata,thistrial,lastpositionVisual,e,frame);
showPositionColorcell array[192 192 192]If showing position, the color of the feedback (each number between 0 and 255). Should be a N * (P*3) array (P= number of dots). Can either have one row, or a row for each frame. If showing image, the imagenumber to show. If it is a cell array, then each cell can specify for an individual trial.
showPositionSizematrix6If showing position and showPositionType is a dot, then a 1*P array (with the size of the each dot in pixels. If type is a rectangle, then a 1*(P*2) array (width and height).
showPositionRotationCentercell array{[0.5 0.5]}If showing position, the center of rotation (if showPositionRotationAngle is not zero). Should be a P * 2 matrix (p = number of dots), in relative screen coordinates (i.e. between 0 and 1)
showPositionRotationAnglecell array{NaN}If showing position, the angle to rotate about the center of rotation (in radians). Should be a P * 1 matrix (p = number of dots), or a cell for each trial with a P*1 matrix
startRotationFramematrix-InfIf showing position, the frame to start the rotation (if there is one). To start before the trial (i.e. while waiting for start), set to -inf. Should be a 1*P matrix (p=number of dots) or N*P (one row for each trial).
displayRangeXcell array{[0 0 0 0 0]}How the values of the device move the dot horizontally when showPosition = 3, 4 or 5. Which values a device gives depends on the device (see "Showing the position" on its page): e.g. x and y for the mouse and tablet, x, y and z for each Liberty sensor, one value per channel for force sensors. For each value, give a pair [min max]: as the value goes from min to max, the dot moves right by the width of the screen (swap them to move left; use 0 0 for values that should not move the dot). After the pairs comes one more number for time: 0 = not used, e.g. 1 = move across the screen in 1 s, -inf = only show before the trial starts, inf = only show during the trial. So a row has 2 * (number of values) + 1 columns, e.g. [-1 1 0 0 0] for the mouse moves the dot with x from -1 to 1. Use one row, or one row for each sensor (each row then uses the values of its own sensor, and the movements of all rows are added). To show several dots, put the columns for each dot one after the other. This is a cell array, with one cell for all trials or a cell for each trial. The size is checked by validate when a trial uses showPosition = 3, 4 or 5.
displayRangeYcell array{[0 0 0 0 0]}How the values of the device move the dot vertically when showPosition = 3, 4 or 5. The same as displayRangeX (and it must be the same size), but as the value goes from min to max the dot moves down by the height of the screen. e.g. [0 0 -10 10 0] for the mouse moves the dot with y from -10 to 10.
offsetXmatrix0.5x offset when using showPosition. This can either be a 1*P matrix [P is the number of dots] (same for every trial), or an NxP matrix (one row for each trial).
offsetYmatrix0.5y offset when using showPosition. This can either be a 1*P matrix [P is the number of dots] (same for every trial), or an NxP matrix (one row for each trial).
