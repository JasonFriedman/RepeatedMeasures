Response

stoppedMoving

Used in trial{n}.targetType

This response is to stop a trial after the subject has stopped moving for a certain amount of time.

NameTypeDefaultDescription
durationnumber0.5The amount of time you need to stop before ending the trial (s)
startDistancenumber0.1The minimum distance from the starting point to be considered moving
startStatenumberNaNThe state you need to be in to be considered starting to move (if using states with image stimuli)
endDistancenumber0Need to move less than or equal to this to be considered not moving
